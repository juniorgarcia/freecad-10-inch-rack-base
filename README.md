# 10" rack shelf template

This is a FreeCad 1.1.0 project that aims to be the base template to create shelves
for 10" racks, like [Lab Rax](https://makerworld.com/en/models/1294480-lab-rax-10-server-rack-5u#profileId-1325352).

The file contains a spreadsheet with properties to be the base to some
calculations, facilitating some aspects of the shelf.

Some dimensions were taken from [this](https://en.wikipedia.org/wiki/19-inch_rack#10-inch_rack) Wikipedia article.
